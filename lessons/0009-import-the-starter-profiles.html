Phase 2 · The filament · L9

Import the starter profiles

Twenty minutes at the desk, no printing. Load six ready-made filament presets so every measurement you take in the next seven lessons has somewhere to live — and know exactly how much to trust them, which is: not yet.

⏱ ~20 minutes, at the computer• 🖨 Nothing printed• Phase 2
◎ Why this lesson

Phase 2 measures seven numbers per spool, and each one needs a preset to be written into. You could start from Prusa's generic profiles and adjust as you go — but then every lesson begins with ten minutes of setup, and the first tower would print with a PETG temperature range meant for a different brand. The bundle below carries a documented starting point for this fleet's two materials on all three machines: eSUN PETG and eSun eTPU-95A, one preset per printer. Import it once, and Lessons 10–16 become pure measurement: run the test, replace one number, save.

⚠ Starting points are not measurements

Every value in these presets comes from the manufacturer's datasheet cross-checked against community results on Prusa hardware — not from your machine or your spool. In the language of the tuning log, every one of them is inherited, not measured. The whole point of Phase 2 is to replace them one by one. What the bundle buys you is a sane place to start and a structure to write into, nothing more.

1What you are importing

⬇ Download

esun-starter-profiles-bundle.ini — a PrusaSlicer config bundle holding six filament presets. The companion document esun-starter-profiles.md tables every value inside it and says where each came from.

Six presets: two materials × three printers.

  • eSun PETG @MK3S 0.4 · eSun PETG @MK4S 0.4 · eSun PETG @COREONE 0.4
  • eSun eTPU-95A @MK3S 0.4 · eSun eTPU-95A @MK4S 0.4 · eSun eTPU-95A @COREONE 0.4

Three properties matter before you click import:

  • They are per-machine, not per-material The same spool of eSUN PETG gets a max volumetric speed of 8 mm³/s on the MK3S and 13–14 mm³/s on the Nextruder machines, and a M900 K advance line on one firmware family versus M572 S on the other. This is the course's one-rule-that-outranks-everything, already baked in — which is why there are six presets and not two.
  • They are self-contained — no inherits Each preset carries every value explicitly rather than referencing a Prusa system profile. That means a PrusaSlicer update can never silently move your baseline — and also that the presets will never pick up Prusa's improvements. For a tuning baseline that trade is deliberate: you want the ground to hold still while you measure.
  • They are scoped by a visibility condition Each preset carries a compatible-printers condition matching one printer family and a 0.4 mm nozzle. A preset that doesn't apply to the selected printer is hidden entirely, with no message. That is a feature — it makes selecting the MK3S numbers on the Core One impossible — but it reads as "my import vanished" until you know it's there.

2Import it

PrusaSlicer, any of your machines selected:

  • File → Import → Import Config Bundle… Point it at esun-starter-profiles-bundle.ini. PrusaSlicer reports how many presets it imported — you want 6.1
  • Find them in the Filament dropdown They appear under User presets, above the system ones. Only the two matching the currently selected printer are visible — the other four are hidden by their conditions, not gone.
  • Check the nozzle if anything seems missing The conditions also require a 0.4 mm nozzle. A printer profile set to 0.6 hides all six. Printing other nozzle sizes is a Lesson 17 topic — duplicate, rename, re-condition, re-tune.
  • Open one and look at Custom G-code The advance starting value lives in each preset's start G-code — that is the line Lesson 12's tower will replace. Find it now so that lesson starts on familiar ground.

Open your machine. Same import on every machine; what you should see afterwards differs.

MK3S · two presets, Marlin numbers

With an MK3S printer profile and 0.4 nozzle selected, the Filament dropdown shows eSun PETG @MK3S 0.4 and eSun eTPU-95A @MK3S 0.4.

Spot-checks that you're looking at the right preset: PETG max volumetric speed 8 mm³/s, TPU 1.8 mm³/s, and the start G-code advance line is M900 K0.07 for PETG — Linear Advance, this machine's firmware family.

The condition matches MK3-family printers, so the presets also appear for an MK3S+ profile. Fine — same machine class.

MK4S · two presets, Buddy numbers, one loose condition

With the MK4S selected: eSun PETG @MK4S 0.4 and eSun eTPU-95A @MK4S 0.4. Spot-checks: PETG MVS 13 mm³/s, advance line M572 S0.05 — Pressure Advance.

Known looseness: these presets' condition matches on /.*MK4.*/, so they would also show for a plain MK4 or MK4S MMU profile. The values were chosen for the MK4S, and Lesson 17 tightens the condition once you've read the real printer_model off the machine. Until then, just don't slice for a printer you don't own.

Core One · two presets, MK4S-class flow, chamber notes

With the Core One selected: eSun PETG @COREONE 0.4 and eSun eTPU-95A @COREONE 0.4. Spot-checks: PETG MVS 14 mm³/s, advance line M572 S0.05.

The numbers sit close to the MK4S ones deliberately — same hotend class, so the flow ceilings match — but they are not identical: cooling is set lower because the enclosure holds heat, and the PETG preset assumes the door closed. The chamber-state discipline from Lesson 10 applies from the very first print.

3How the presets get better than the bundle

From Lesson 10 onward the workflow is always the same: run the test, take the measurement, type it into the matching preset, and Save over the same preset name — the ⟳/💾 icon beside the Filament dropdown, keeping the exact name. The preset accretes measured values one lesson at a time, and the name keeps meaning "the current best state of this material on this machine".

Never write your numbers into a Prusa system profile — those belong to Prusa and get replaced on update. That rule, the naming scheme, and backups all get their full treatment in Lesson 17; for now the bundle's names are already shaped the way that lesson wants them.

When a preset has real measurements in it, export your own bundle as a backup: File → Export → Export Config Bundle…. The file you downloaded today is the starting state; the one you export after Phase 2 is the first artefact of this course actually worth keeping.1

What you can now say

  1. Six presets, two materials × three machines — because advance commands, flow ceilings and cooling genuinely differ per printer, the fleet's one unbreakable rule.
  2. Every value in them is inherited, not measured. Phase 2 exists to replace them, one lesson at a time, saving over the same preset name.
  3. A hidden preset is usually a visibility condition doing its job — check the selected printer and the 0.4 nozzle before suspecting the import.
  4. Self-contained means stable ground: no system-profile update can move the baseline while you're measuring against it.
  5. Export your own bundle once real measurements land — that file, not this one, is the artefact worth backing up.
