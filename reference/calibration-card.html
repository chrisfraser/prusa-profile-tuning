▲ Never mix these two

MK3S = Marlin. Linear Advance, M900 K, values ~0.02–0.08 for a 0.4 nozzle.
MK4S / Core One = Buddy. Pressure Advance, M572 S.
Different features, different scales, no conversion between them. One profile per printer family.

1The order — never out of sequence

Changing any step voids every measurement below it.
#StepWhy it sits here
0The machine (Phase 1)Everything below measures filament plus machine
1TemperatureSets viscosity — moves every number below it
2Extrusion multiplierMeasured at the temperature just fixed
3Pressure / Linear AdvancePressure depends on viscosity and flow
4RetractionOoze depends on residual pressure, which advance changed
5CoolingModifies temperature's effect after the nozzle
6Max volumetric speedDepends on temperature; silently clamps speeds
7Speeds and accelerationsBounded by all of the above — and can send you back to 3

The one legitimate loop back: advance must be tuned at production accelerations. Print the advance tower with your real quality profile loaded, not a slow one.

⌁ Diagnostic thresholds worth memorising

Hotend swing ≤ ±5 °C → PID tuning. > ±5 °C → fan, thermistor or connector fault, not tuning.
Input Shaper frequency outside 35–70 Hz → go back to belts and assembly.
MK3S axis-length error → suspect belt tension before suspecting the axis.
Defect varies by position on the plate → bed shape, not Z offset.
Defect appears partway up the print → not belts; look at chamber heat or accumulated mass.

4The arithmetic

The extrusion equation
volumetric flow (mm³/s) = layer height × extrusion width × print speed

# rearranged, to find the speed that saturates a given flow
speed = flow ÷ (layer height × extrusion width)

# extrusion multiplier, from a measured single wall
new EM = current EM × (nominal wall width ÷ measured wall width)

# total flow is the product of two independent scalars
total flow = M221 (firmware, %) × extrusion multiplier (slicer)
Practical flow ceilings, 0.4 mm nozzle — starting figures, to be replaced by measurements.

6Method rules

The habits, compressed.
RuleBecause
One variable between two test printsTwo changes give a result you can't attribute — worse than none, because it feels like data
Banded test prints over separate printsSame spool, nozzle, hour and humidity — only the variable differs
Dry the filament firstMoisture makes prints non-reproducible, which corrupts temp, flow and retraction at once
Tune advance at production speedA slow-test value over-compensates and starves corners at real speed
Delete test G-code afterwardsIt lives in the printer profile and keeps firing on unrelated prints forever
Log printer, spool, colour, datePigment changes flow within a brand; an unlogged number is indistinguishable from a guess
Snap the part to judge bondingGranular fracture = fused. Clean plane along a layer = laminated. Surface tells you nothing

7Shipping a profile

Naming and scoping
# <Vendor> <Material> @<PRINTER> <nozzle>
eSun PETG @MK3S 0.4      eSun PETG @MK4S 0.4      eSun PETG @COREONE 0.4

# Filament Settings → Dependencies → Compatible printers condition
printer_model=~/.*MK3.*/     and nozzle_diameter[0]==0.4
printer_model=~/.*MK4.*/     and nozzle_diameter[0]==0.4
printer_model=~/.*COREONE.*/ and nozzle_diameter[0]==0.4

# Filament Settings → Custom G-code → Start G-code — NEVER printer start G-code
M900 K0.07   ; MK3S only
M572 S0.05   ; MK4S / Core One only

# Backup, after every session
File → Export → Export Config Bundle

Verify printer_model by slicing and reading the config comments at the end of the G-code. Never tighten a regex you haven't confirmed — an over-strict condition hides the profile silently.

Validation — each failure names the step to go back to.
CriterionFailure means
Top surface uniformpinholes or ridges → L10 extrusion multiplier
Corners squarebulge → advance low · gap after corner → advance high → L11
Seam a fine lineL11 advance + L12 retraction, then scarf seams
Layer lines evendegrading upward → L13 cooling / L14 MVS (Core One: chamber)
Snap test granularclean layer plane → L9 temperature or too much fan

Three prints: dimensional cube (±0.15 mm, and X must agree with Y) · overhang/bridge/stringing combo · a real part of your own. Elephant foot compensation last — Print Settings → Advanced, ~0.2 mm for a 0.4 nozzle. Record the scope: material, machine, speeds, enclosure state, date.

Log every value (m) measured or (i) inherited. Record date, printer, spool including colour, and when it was dried. A profile of (i) values is a hypothesis; a profile of (m) values is a measurement.
